Connect GitHub
  1. Open GitHub › new fine-grained token.
  2. Under Repository access, choose Only select repositories and pick codrops-feed.
  3. Under Permissions › Repository › Contents, choose Read and write. Nothing else is needed.
  4. Generate it and paste it below. It's saved in this browser only.

Feeds live in the codrops-feed repo. Builds run in Actions.
